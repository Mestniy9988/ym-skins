# YM Skins — техническое задание

Репозиторий содержит техническое задание на систему скинов в стиле Winamp для desktop-приложения «Яндекс Музыка» (Windows, опционально macOS).

- [TZ.pdf](./TZ.pdf) — ТЗ в формате PDF (A4, 13 страниц).
- [TZ.md](./TZ.md) — исходник ТЗ: архитектура, механизм работы после обновлений, перечень из 12 скинов, визуализатор и мини-плеер, этапы, поддержка, риски.

## Пересборка PDF

Нужны Python 3 и Google Chrome или Chromium.

```bash
python3 -m pip install markdown
python3 scripts/build_pdf.py
```
