# YM Skins — техническое задание и прототип скинов

Репозиторий содержит техническое задание на систему скинов в стиле Winamp для desktop-приложения «Яндекс Музыка» (Windows, опционально macOS) и интерактивный прототип минималистичного интерфейса со всеми 12 скинами.

- [TZ.pdf](./TZ.pdf) — ТЗ в формате PDF (A4, 21 страница, включая Приложение А со скриншотами).
- [TZ.md](./TZ.md) — исходник ТЗ: архитектура, минималистичный интерфейс, раздел «Оформление» в Настройках, механизм работы после обновлений, 12 скинов, визуализатор и мини-плеер, этапы, поддержка, риски.
- [preview/](./preview) — прототип интерфейса (Vite, React, TypeScript, Tailwind, shadcn/ui).
- [docs/img/](./docs/img) — скриншоты прототипа, которые используются в ТЗ.

## Прототип

Интерфейс сокращён до трёх разделов и Настроек:

- **Моя волна** — стартовый экран: сейчас играет, настроение, очередь;
- **Моя музыка** — понравившиеся треки;
- **Поиск** — поиск трека, недавние запросы, популярное;
- **Настройки** — оригинальные настройки плюс раздел «Оформление»: выбор скина, окно примера, выбор темы, кнопка «Применить скин» и переключатель «Оригинальная тема».

Вверху страницы четыре готовых примера (разные скины на разных экранах). Кнопки плеера, выбор трека, «Нравится» и поиск работают. Звук не воспроизводится: визуализатор работает на синтезированном сигнале.

Состояние хранится в адресе страницы, поэтому на любой экран можно дать ссылку. Параметры: `ex` (номер примера 1–4), `skin`, `theme` (id темы, например `oak`), `page` (`wave`, `music`, `search`, `settings`), `q` (поисковый запрос), `original=1` (оригинальная тема), `embed=1` (только окно приложения 1120×700, для скриншотов). Например: `#skin=neon&page=search&q=ноч`.

Запуск (нужен Node.js 20+):

```bash
cd preview
npm install
npm run dev      # http://localhost:47123
```

Сборка статической версии: `npm run build`, результат — в `preview/dist`.

## Пересборка PDF

Нужны Python 3 и Google Chrome или Chromium.

```bash
python3 -m pip install markdown
python3 scripts/build_pdf.py
```

Скриншот любой страницы: `python3 scripts/screenshot.py <url> <out.png> [ширина] [высота]`, например `python3 scripts/screenshot.py "http://127.0.0.1:47123/#skin=aqua&page=settings&embed=1" docs/img/screen-settings.png 1120 700`.
