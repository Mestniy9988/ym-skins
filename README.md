# YM Skins — техническое задание и прототип скинов

Неофициальный инструмент. Он не связан с правообладателем приложения и не меняет подписку, скачивание, рекламу и данные аккаунта.

Репозиторий содержит техническое задание на систему скинов для desktop-приложения «Яндекс Музыка» (Windows, опционально macOS), интерактивный макет интерфейса и короткий прототип проверки внедрения.

## Проверка внедрения на Windows

Прототип в [poc/](./poc) — это скрипт на Node.js, без Tauri и без каталога скинов. Он ищет установленный клиент, читает Electron Fuses, не изменяя файлы, и на Windows или Linux запускает клиент с отладочным портом только на `127.0.0.1`. Через CDP скрипт красит фон и одну кнопку, перезапускает именно тот процесс, который сам открыл, и проверяет, что тот же эффект снова ставится. Архив `app.asar` не модифицируется и проверка целостности не обходится. Токены, cookies и данные аккаунта скрипт не читает.

База, под которую написан прототип: Windows 11 25H2 и клиент 5.121.2. Фактические путь и версию скрипт берёт с машины. Если их прочитать не удалось, в отчёте стоит «не проверено». Прогон на Linux не заменяет проверку Windows-сборки.

Скрипт ищет клиент в стандартных каталогах и в папках вида `app-<версия>`. На Linux это `/opt/Яндекс Музыка`, `/opt/yandexmusic` и `~/.local/opt` с теми же именами: рядом с бинарником `yandexmusic` должен лежать `resources/app.asar`. Процесс клиента отделён от скрипта, поэтому после успешного прогона окно остаётся открытым. Внутри одного прогона скрипт сначала завершает свой процесс и дожидается, пока тот пропадёт, и только потом запускает клиент снова.

На Linux профиль пишется во временный каталог, не в домашний профиль пользователя. Если `chrome-sandbox` без setuid, к этому запуску добавляется `--no-sandbox`; на обычной установке с setuid этот флаг не ставится. Для окна добавляется `--gtk-version=3`. Заметка о пакете 5.121.2: [poc/STAGE1-LINUX.md](./poc/STAGE1-LINUX.md).

Нужен Node.js 20 или новее. Перед запуском закройте клиент: уже открытое окно скрипт не завершает.

```bash
cd poc
node probe.mjs
```

Отчёт пишется в `poc/out/stage1-report.md`. После успешной проверки окно остаётся открытым со стилем. Снять его:

```bash
node probe.mjs --restore
```

Модульные тесты разбора Fuses, заголовка ASAR, отчёта и отказа на Linux, без клиента:

```bash
cd poc
node --test
```

## Техническое задание и макет

- [TZ.pdf](./TZ.pdf) — ТЗ в формате PDF (A4, 21 страница, включая Приложение А со скриншотами).
- [TZ.md](./TZ.md) — исходник ТЗ: архитектура, минималистичный интерфейс, раздел «Оформление» в Настройках, механизм работы после обновлений, 12 скинов, визуализатор и мини-плеер, этапы, поддержка, риски.
- [preview/](./preview) — прототип интерфейса (Vite, React, TypeScript, Tailwind, shadcn/ui).
- [docs/img/](./docs/img) — скриншоты прототипа, которые используются в ТЗ.

## Прототип

Интерфейс сокращён до трёх разделов и Настроек:

- **Моя волна** — стартовый экран: сейчас играет, настроение, очередь;
- **Моя музыка** — понравившиеся треки;
- **Поиск** — поиск трека, недавние запросы, популярное;
- **Настройки** — оригинальные настройки плюс раздел «Оформление»: выбор скина, окно примера, выбор темы, кнопка «Применить скин» и переключатель «Оригинальная тема».

Вверху страницы четыре готовых примера (разные скины на разных экранах). Кнопки плеера, выбор трека, «Нравится» и поиск работают. Звук не воспроизводится: визуализатор работает на синтезированном сигнале.

Состояние хранится в адресе страницы, поэтому на любой экран можно дать ссылку. Параметры: `ex` (номер примера 1–4), `skin`, `theme` (id темы, например `oak`), `page` (`wave`, `music`, `search`, `settings`), `q` (поисковый запрос), `original=1` (оригинальная тема), `embed=1` (только окно приложения 1120×700, для скриншотов). Например: `#skin=neon&page=search&q=ноч`.

Запуск (нужен Node.js 20+):

```bash
cd preview
npm install
npm run dev      # http://localhost:47123
```

Сборка статической версии: `npm run build`, результат — в `preview/dist`.

## Пересборка PDF

Нужны Python 3 и Google Chrome или Chromium.

```bash
python3 -m pip install markdown
python3 scripts/build_pdf.py
```

Скриншот любой страницы: `python3 scripts/screenshot.py <url> <out.png> [ширина] [высота]`, например `python3 scripts/screenshot.py "http://127.0.0.1:47123/#skin=aqua&page=settings&embed=1" docs/img/screen-settings.png 1120 700`.
