# YM Skins — техническое задание и визуализация скинов

Репозиторий содержит техническое задание на систему скинов в стиле Winamp для desktop-приложения «Яндекс Музыка» (Windows, опционально macOS) и интерактивную визуализацию всех 12 предложенных скинов.

- [TZ.pdf](./TZ.pdf) — ТЗ в формате PDF (A4, 13 страниц).
- [TZ.md](./TZ.md) — исходник ТЗ: архитектура, механизм работы после обновлений, перечень из 12 скинов, визуализатор и мини-плеер, этапы, поддержка, риски.
- [preview/](./preview) — веб-галерея скинов (Vite, React, TypeScript, Tailwind, shadcn/ui).

## Визуализация скинов

Для каждого скина из раздела 6.2 ТЗ показаны:

- **главное окно** — схематичный макет «Яндекс Музыки» (меню, «Моя волна», очередь, панель плеера с LCD-дисплеем);
- **мини-плеер** — компактное окно в компоновке Winamp 2.x с эквалайзером;
- **все 12** — мини-плееры всех скинов на одном экране;
- две цветовые темы, описание концепции, элементов и анимаций.

Кнопки плеера, выбор трека, перемотка и «Нравится» работают. Звук не воспроизводится: визуализатор работает на синтезированном сигнале. Выбранный скин, тема и вкладка сохраняются в адресе страницы, например `#skin=vinyl&theme=oak&view=mini`, поэтому на конкретный скин можно дать ссылку.

Запуск (нужен Node.js 20+):

```bash
cd preview
npm install
npm run dev      # http://localhost:47123
```

Сборка статической версии: `npm run build`, результат — в `preview/dist`.

## Пересборка PDF

Нужны Python 3 и Google Chrome или Chromium.

```bash
python3 -m pip install markdown
python3 scripts/build_pdf.py
```

Скриншот любой страницы: `python3 scripts/screenshot.py <url> <out.png> [ширина] [высота]`.
